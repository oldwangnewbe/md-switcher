# 决斗匣 · DuelShelf for Windows

适用于 Windows 10/11 x64。请解压整个 ZIP，然后运行 `DuelShelf.exe`。保留旁边的 `CardEngine` 和 `RoyalFinish` 文件夹。包内已附运行所需组件。

## 第一次使用

1. 在 Steam 中登录并记住账号，再打开换号器。「账号切换」同时显示账号备注、Steam 登录名和绑定的 `LocalData` 文件夹。点右侧「改备注」可给账号起个容易记的名字。
2. 选中已下载完整资源的账号，点「设为资源主账号」，选它的游戏文件夹。其他账号先打开游戏一次，见到标题画面后退出，再回到换号器点「绑定游戏目录」。绑定列表会标出已归属其他账号的文件夹。
3. 选中已绑定的小号，点「快速共享主号缓存」后启动。以后选好账号，点「启动 MD」即可。如果 Steam 已登录所选账号，会直接启动游戏；需要 Steam Guard 时请在 Steam 中完成。

换号器会自动查找 Steam、Master Duel 和 MDPro3。「设置」只管理安装目录，重新检测不会清除账号备注或绑定。MDPro3 用于卡片搜索和异画，可按需连接。

## 游戏资源和异画

「快速共享主号缓存」为小号的 `0000` 缓存建立 NTFS 目录联接，无需逐文件读盘或建链接。共享期间，游戏资源、索引和异画与主号同步。原缓存保留在原盘，可在账号详情点「恢复原缓存」。需要单独应用异画时，请先恢复。更改共享方式前请退出游戏。 [Microsoft 目录联接说明](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/mklink)

小号保持独立缓存时，通过换号器启动仍可复用主号已下载的原版资源。首次补齐缺少的文件需要读盘核对，进度会显示文件数、共享量和实际写入量。

同一个 NTFS 卷上的账号使用逐文件硬链接，直接引用已下载的原版资源。已经存在的文件保留原样，账号索引独立保存。换号器应用异画时会替换该账号的文件，断开它与原版的链接。如果游戏原地改写共享文件，其他引用该文件的账号也会读到改动。 [Microsoft 硬链接说明](https://learn.microsoft.com/en-us/windows/win32/fileio/hard-links-and-junctions)

支持块克隆的 ReFS 卷继续使用块克隆。已有完整缓存的账号可以直接启动。需要补资源但磁盘不支持共享时，可先用「仅切换 Steam」登录账号。

从左侧打开「卡片搜索」，输入卡名、编号或系列。选中卡片后，可预览原画、普通异画和超框异画。退出游戏后，点「应用异画」或「恢复原画」。勾选「所有账号」可一起处理各已绑定的独立缓存。使用快速共享的小号跟随主号；要单独设置，先恢复小号原缓存。缺少卡图时，请先在该账号中打开对应卡片，等资源下载完成后退出游戏。

左侧「异画合集」内置闪刀姬、烙印和黑魔导。可调整每张卡的异画、移出卡片，或在「卡片搜索」选好异画后用「加入合集」保存到自建合集。点「应用整套」或「恢复原画」即可批量操作。首次打开卡库会建立本机索引，之后复用缓存。

## 动态镜碎

在「账号切换」选中 Steam 账号，再进入「动态镜碎」。可搜卡片逐张设置，或通过「按合集」整组开启和关闭。「已开启」列出当前账号的选择。菜单也可将同一设置应用到所有 Steam 账号。

设置在下次启动游戏时生效。保持换号器运行，从「启动 MD」或 Steam 启动游戏都会按实际登录的账号加载。镜碎效果仅在本机显示，卡片的游戏内品质由服务器记录。

## 使用风险

异画会改动本地游戏资源，动态镜碎会向游戏进程加载渲染 DLL。使用前请备份，并核对游戏和平台条款。游戏更新后可能失效或崩溃，运营方也可能限制账号。本项目仅供个人学习和非商业使用，按现状提供。ZIP 仅包含程序与依赖，素材来自本机 MDPro3。

## 构建

在 macOS 项目目录运行 `bash Windows/build.sh`，交叉构建 Windows x64 ZIP。需要 .NET 10 SDK、带 pip 的 Python，以及 curl、zip 和 unzip。镜碎组件复用 Mac 版的构建脚本。可通过 `DOTNET_EXE` 和 `PYTHON_EXE` 指定开发机的工具路径。
