# MD 换号器 · Windows 0.2

适用于 Windows 10/11 x64。请解压整个 ZIP，然后运行 `MD Switcher.exe`。保留旁边的 `CardEngine` 文件夹。

## 账号与安装目录

在 Steam 中登录账号并选择记住登录。Steam 已登录所选账号时，可直接点「启动 MD」。切换账号前请退出游戏。若需要 Steam Guard，在 Steam 窗口中完成。

换号器会自动查找 Steam、Master Duel 和 MDPro3。「设置」里可重新检测或手动选择目录，选择保存在本机。

## 游戏资源和异画

选中已下载完整资源的主账号，在「设置」中点「设为资源主账号」，选择它在游戏 `LocalData` 下的账号文件夹。小号先进入游戏一次生成目录，退出后在换号器选中它，再点「绑定小号资源」。之后通过换号器启动该小号时，会复制缺失的资源。首次复制耗时和所需空间取决于缺失资源量。

打开「卡片搜索 · 异画」后，输入两款游戏中任一边的卡名、编号或系列，或用闪刀姬、烙印、黑魔导筛选。选择异画预览，退出游戏后应用。可对当前账号或所有已绑定账号操作，也可以恢复原画。某账号的资源尚不完整时，先从换号器启动一次该账号，待资源准备完成后再试。

首次搜索建立本机索引，之后复用缓存。当前 Windows 版支持卡图，召唤动画仍待移植。

## 构建

在项目目录运行 `bash Windows/build.sh`。需要 .NET 10 SDK、带 pip 的 Python，以及 curl、zip 和 unzip。可通过 `DOTNET_EXE` 和 `PYTHON_EXE` 指定开发机的工具路径。
